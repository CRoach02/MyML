# MyML

My code for learning C++ and ML library systems.

This is an indefinite work-in-progress project. My primary goal is to be able to hand-roll ML tasks whether it be from research papers or generic implementations. 

The backing project's feature complete state will be a basic library for handling tensor operations in C++. Future changes/additions may bring support for neural networks and related operations.

Structure
- Interface Layer: Python
- Connection/Binding Layer: Nanobind
- Computation Layer: C++
